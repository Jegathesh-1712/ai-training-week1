# Week 1 Day 5 - Second Half
## Employee Data Analysis and Visualisation

### Project Overview
This project analyzes employee data using Python, Pandas, Matplotlib and Seaborn.

### Dataset
File: data/employees.csv

Contains employee ID, name, department, salary and city.

### Visualisations
1. Department Salary Bar Chart
2. Employee Salary Histogram
3. Employee Salary Scatter Plot
4. Sorted Salary Line Chart
5. Employee Salary Box Plot

### Project Structure
- data/ - Employee dataset
- notebooks/ - Jupyter notebook
- reports/figures/ - Five generated charts
- reports/summary.md - Findings summary
- reports/employee_analysis.html - HTML report

### Installation
Install the required libraries:

```bash
pip install -r requirements.txt
```

### Run the Notebook
```bash
jupyter notebook
```

Open:
notebooks/employee_analysis.ipynb
