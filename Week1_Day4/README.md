Week 1 - Day 4 Assessment

Project Title

Employee Data Analysis

Project Overview

This project focuses on analysing employee data using Python and Pandas.

Dataset

IBM HR Analytics Employee Attrition Dataset.

Tools and Technologies

- Python
- Pandas
- Jupyter Notebook
- VS Code
- Git and GitHub

Tasks Completed

Task 1: Terminal, VS Code and Jupyter

- Practised Linux terminal commands.
- Used grep to search employee records.
- Configured Python and Pylance in VS Code.
- Created a Jupyter notebook.
- Compared execution time using %timeit.
- Exported the notebook into a Python file.

Task 2: Employee Data Analysis

- Loaded the employee dataset using Pandas.
- Checked dataset shape and information.
- Generated statistical summaries.
- Checked missing values.
- Checked duplicate records.

Business Questions

1. Which department has the highest employee attrition?
2. Does overtime affect employee attrition?
3. Which age group has the highest employee attrition?
4. Does monthly income affect employee attrition?
5. Which job role has the highest employee attrition?

Project Structure

- data/ - Dataset files
- notebooks/ - Jupyter notebooks and Python files
- reports/ - Analysis reports and data dictionary
